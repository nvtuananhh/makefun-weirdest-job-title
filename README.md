## What it does

`main.py` (Python 3, standard library only, no network) writes one
weird job title to `/output/entry.txt`:

> Senior Apologizer for Self-Driving Cars

The title is 39 characters long. It lands on the judge's
brief: a real-sounding corporate title with one hilariously
specific twist — a senior apologizer whose clients are
self-driving cars, which keep needing someone to say sorry on
their behalf. It reads instantly, it is specific enough to
picture the person doing it, and the twist lands on the first
read: the cars cannot apologize, so a human has to do it for
them.

## How to run

```sh
python3 main.py
```

## Output

Writes one job title (39 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
